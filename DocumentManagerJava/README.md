# Менеджер документов — Java 17

## Функции
- Создание накладной, платёжки и заявки на оплату.
- Просмотр одного выбранного документа.
- Сохранение/загрузка списка в текстовый файл UTF-8.
- Удаление нескольких документов по галочкам.
- Интерфейс адаптируется при изменении размера окна.

## Запуск
1. Распакуйте архив.
2. В IntelliJ IDEA выберите File → Open и откройте папку `DocumentManagerJava`.
3. Укажите JDK 17 в File → Project Structure → Project SDK.
4. Откройте `src/main/java/ru/documents/Main.java`.
5. Нажмите зелёный треугольник рядом с `main` → Run.

Внешние библиотеки и Maven не нужны — достаточно JDK 17.
