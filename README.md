Менеджер документов

Небольшое настольное приложение на Java 17 и Swing для учёта документов: накладных, платёжек и заявок на оплату. Работает без внешних библиотек и без Maven.

Возможности
Создание документов трёх типов: накладная, платёжка, заявка на оплату.
Проверка ввода: все поля обязательны, дата в формате ГГГГ-ММ-ДД, числовые поля не могут быть отрицательными (допустима и точка, и запятая).
Просмотр одного выбранного документа.
Удаление сразу нескольких документов по галочкам, с подтверждением.
Сохранение списка в текстовый файл (UTF-8) и загрузка из него.
Интерфейс подстраивается под размер окна (минимум 760×500).
Типы документов и поля
Тип	Поля
Накладная	номер, дата, пользователь, сумма, валюта, курс валюты, товар, количество
Платёжка	номер, дата, пользователь, сумма, сотрудник
Заявка на оплату	номер, дата, пользователь, контрагент, сумма, валюта, курс валюты, комиссия
Требования
JDK 17 или новее.

Структура проекта
DocumentManagerJava/
├── README.md
└── src/main/java/ru/documents/
    └── Main.java      # весь код: модель документов, сохранение, окно и форма

Классы внутри Main.java:

Doc — базовый класс документа; наследники Invoice, Payment, Request.
Storage — сохранение и загрузка файла.
Window — главное окно со списком и кнопками.
Form — диалог создания документа с проверкой ввода.
Ограничения
Данные хранятся в памяти и записываются на диск только по кнопке «Сохранить в файл».
Редактирование созданных документов не предусмотрено: можно только удалить документ и создать заново.
